# 🏫 校园二手交易平台

## 📖 项目简介

校园二手交易平台是一个专为在校师生打造的闲置物品交易系统。平台致力于解决校园内闲置资源浪费问题，为师生提供一个安全、便捷、高效的二手交易环境。无需离校，即可轻松发布、浏览和交易校园内的闲置物品。

---

## 🎯 核心功能

### 👤 用户模块
- **用户注册/登录**：支持普通用户和管理员两种角色登录
- **个人中心**：查看和编辑个人资料，管理发布的商品
- **消息通知**：实时接收交易消息和系统通知

### 📦 商品模块
- **商品发布**：填写商品信息（名称、描述、价格、图片等），一键发布
- **商品浏览**：首页展示热门和最新商品
- **商品搜索**：按关键词、分类、价格区间等条件搜索商品
- **商品详情**：查看商品完整信息、卖家信息，支持收藏和联系卖家

### 💰 交易模块
- **订单管理**：查看订单状态（待付款/待发货/已完成）
- **支付功能**：支持支付宝在线支付
- **交易记录**：查看历史交易记录

### 🛠️ 平台管理
- **用户管理**：管理员可查看和管理所有用户
- **商品审核**：管理员可审核商品信息
- **数据统计**：查看平台交易数据、用户活跃度等

---

## 🛠️ 技术栈

### 前端
- **Vue 2.x**：渐进式 JavaScript 框架
- **Vue Router**：页面路由管理
- **Axios**：HTTP 请求库
- **Element UI**：UI 组件库
- **ECharts**：数据可视化图表

### 后端
- **Spring Boot**：Java 后端框架
- **MyBatis**：ORM 框架
- **MySQL**：关系型数据库
- **Redis**：缓存数据库
